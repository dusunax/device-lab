# 문서 규칙

## 위치

문서는 모두 루트 `docs/` 아래에서 관리합니다.

```text
docs/e-paper/
docs/shared/
```

기능군 문서:

```text
docs/{feature}/
```

공통 문서:

```text
docs/shared/
```

## 언어

작성 주체가 이 저장소인 README와 문서는 한글을 기본으로 합니다.
고유명사, 보드명, 라이브러리명, Arduino IDE 설정명은 영어를 유지할 수 있습니다.

## 내용 기준

- 감성 표현보다 기능, 구조, 검증을 우선합니다.
- 실제 확인하지 않은 하드웨어 동작은 완료로 쓰지 않습니다.
- 선택하지 않을 포트처럼 검증 전에 제외를 확정하는 표현은 피합니다.
- 폴더 구조 변경이 생기면 README와 관련 문서를 함께 갱신합니다.
