# e-paper 기능 체크리스트

`Snow`의 e-paper 기능 검증을 PR 단위로 진행하기 위한 체크리스트입니다.

## 진행 원칙

- 하나의 기능 또는 검증 묶음마다 PR을 분리합니다.
- e-paper 관련 문서는 `docs/e-paper/`를 기준 위치로 둡니다.
- 여러 기기에 공통으로 쓰는 문서만 `docs/shared/`에 둡니다.
- `secrets.h`는 커밋하지 않습니다.
- IP 주소는 e-paper 화면과 Serial Monitor에 표시하지 않습니다.
- 하드웨어 동작이 필요한 항목은 실제 기기에서 확인한 뒤 상태를 변경합니다.
- 체크리스트 상태는 의도나 계획이 아니라 실제 확인 결과 기준으로 표시합니다.

## 체크리스트
